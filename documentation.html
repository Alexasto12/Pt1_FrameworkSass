Redesing

CSS Framework based on SASS

Version 1.0.0

By Alejandro Cabrera Carrasco

This project is a simple CSS framework exercise created during a class to explore and practice fundamental web design techniques using SASS. It is a basic framework named "REDESIGN," focusing on styling forms, navigation bars, tables, buttons, and grids with predefined classes. The framework includes flexible and responsive layouts and showcases how to implement CSS properties effectively. The styles are straightforward and aimed at understanding concepts rather than achieving a production-level quality. This exercise is not intended to be a serious or professional project but rather a learning tool to demonstrate the application of CSS and SASS for real-world scenarios.

NAVIGATION BAR

The .nav-horizontal class is designed to style horizontal navigation bars. It uses flexbox for layout, centering the navigation items both horizontally and vertically. The navigation bar spans the full width of the container and includes padding for spacing. The text is styled with a dark blue color, a font size of 1.2rem, bold weight, and uppercase transformation. The ul element within the navigation bar is also displayed as a flex container, with its items arranged in a row and centered horizontally. Each li element has horizontal margins for spacing, and the a elements inherit the text color, have no text decoration by default, but underline on hover.

BUTTONS

The button classes are designed to style buttons with different appearances and behaviors. The `.dark-button` class provides a dark primary background with white text, no border, and rounded corners. It uses flexbox for layout and includes padding for a comfortable click area. On hover, the background lightens, and the text color changes to black, with a smooth transition effect. The `.light-button` class offers a light primary background with black text, no border, and rounded corners. It also uses flexbox for layout and includes padding. On hover, the background darkens, and the text color changes to white, with a smooth transition effect. The `.dark-button2` class features a dark secondary background with white text, no border, and rounded corners. It uses flexbox for layout and includes padding. On hover, the background lightens, and the text color changes to black, with a smooth transition effect. HORIZONTAL FORMS

The .form-horizontal class is designed to style horizontal forms. It uses flexbox for layout, allowing form elements to wrap and align centrally. The form has padding, a maximum width of 75% of the viewport, and a transparent border that changes to white on hover with a smooth transition. Labels have left and right margins for spacing. Input, select, and textarea elements are styled with padding, borders, rounded corners, and responsive widths, changing border color on focus. The submit button, styled with the .submit-horizontal class, has padding, rounded corners, a red background that darkens on hover, and a white text color.






VERTICAL FORMS

The .form-vertical class is designed to style vertical forms. It uses a block layout, allowing form elements to stack vertically. The form has padding and a transparent border that changes to white on hover with a smooth transition. Labels are placed above the form controls. Input, select, and textarea elements are styled with padding, borders, rounded corners, and responsive widths, changing border color on focus. The submit button, styled with the .submit-vertical class, has padding, rounded corners, a red background that darkens on hover, and a white text color.







TABLE STRIPPED / NORMAL

The .dark-table class is designed to style tables with a dark theme. It provides a dark gray background with white text and borders. Table cells (td) have a light gray border. The .light-table class is designed to style tables with a light theme. It provides a white background with dark gray text. Table cells (td) have a black border. The .table-striped class is designed to style tables with alternating row colors for better readability. The th elements (table headers) have a white background and black text. The tr elements (table rows) use a mixin called stripe-color to alternate the background and text colors. Even rows have a white background with black text, while odd rows have a black background with white text.

GRID RESPONSIVE

The `.grid` class is designed to style grid items. It provides padding, centered text, bold font weight, and a specific text color. Each grid item occupies 33% of the container's width. The items have rounded corners, a box shadow for a subtle 3D effect, and a smooth transition for all properties. On hover, the grid items scale up slightly, creating a zoom-in effect with a smooth transition.

Conclusion

This project demonstrates the effective use of SASS to create a basic, responsive, and versatile CSS framework. By focusing on essential components like navigation bars, buttons, forms, tables, and grids, it showcases how modern web design principles can be applied to build user-friendly and accessible interfaces. While the framework is intended as an educational exercise rather than a production-ready solution, it highlights the power of modular and reusable styling in web development. The result is a clean and organized approach to styling, suitable for exploring advanced concepts and honing design skills.
