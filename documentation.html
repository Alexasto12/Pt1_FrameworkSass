HORIZONTAL FORMS

The .form-horizontal class in the provided SCSS file is designed to style horizontal forms. It uses flexbox for layout, allowing form elements to wrap and align centrally. The form has padding, a maximum width of 75% of the viewport, and a transparent border that changes to white on hover with a smooth transition. Labels have left and right margins for spacing. Input, select, and textarea elements are styled with padding, borders, rounded corners, and responsive widths, changing border color on focus. The submit button, styled with the .submit-horizontal class, has padding, rounded corners, a red background that darkens on hover, and a white text color.
